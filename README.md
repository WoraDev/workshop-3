# temp-frontend

Minimal Vite + React project created inside existing folder as requested.

How to run locally

1. Install dependencies

```bash
cd /Users/worawoot.k/Documents/temp-frontend
npm install
```

2. Start dev server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
npm run preview
```

Git

To push to a remote repository (replace <remote-url>):

```bash
git init
git add -A
git commit -m "chore: initialize vite + react app"
git branch -M main
git remote add origin <remote-url>
git push -u origin main
```
